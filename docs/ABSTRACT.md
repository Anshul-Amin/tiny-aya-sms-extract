Indian finance apps read billions of bank and UPI transaction SMS a year, often by sending each message to a closed LLM API. We show that a small open model can do this job reliably, cheaply and on-premise, in English, Hindi (Devanagari) and code-mixed Hinglish.

We fine-tune Cohere Labs' Tiny Aya Global (3.35B) with LoRA, and repeat the identical run on the South-Asia-specialised Tiny Aya Fire, using a pipeline that chains three Lexsi toolkits: CuratorKIT (cleaning, de-duplication, provenance, plus a JSON quality gate), AlignTune (SFT with the TRL backend on one free T4 GPU) and AuditKIT (evaluation harness for every system and split). The model reads one SMS and returns one schema-valid JSON object with 11 fields: transaction flag, type, amount, currency, account, instrument, counterparty, date, reference, balance and status.

The training data is synthetic, then curated. A generator labels a field only if its text survives generation, which makes hallucination measurable, and every training row then passes through CuratorKIT (cleaning, de-duplication, provenance) and a JSON quality gate. It covers 14 message families, including five hard-negative families (OTPs, offers, bill reminders, future debits, balance alerts) that mention money but are not transactions. It also covers edge cases: Indian digit grouping, credit-limit distractors, foreign currency, truncation, Devanagari digits, missing spaces and casing noise. Bank names are fictional. To measure generalisation rather than memorisation, one template per family and language is held out entirely (test_ood). We also evaluate on a hand-written challenge set of realistic, messy messages.

On unseen formats the fine-tuned model reaches 85.0% exact match (all 11 fields correct), against 21.0% for few-shot prompting of the same model. On the hand-written set it reaches 70.5%, against 25.0% few-shot, 9.1% zero-shot and 25.0% for a hand-written regex parser. Its hallucination rate there is 10.1% (few-shot: 25.3%). An ablation trained on the same amount of clean data, without hard negatives or noise, reaches 47.7% exact match and 13.3% non-transaction F1 (full model: 70.5% and 81.5%), which isolates the effect of the robustness data. With the same data and settings, Tiny Aya Fire scores higher still: 88.7% on unseen formats and 79.5% on the hand-written set (86.0% on Hinglish, against 79.6% for Global), at the same speed. Both fine-tunes beat every baseline on every split (paired McNemar tests, p < 1e-6), and bootstrap intervals are reported.

At a realistic 10,000,000 SMS per month, self-hosting on a T4 costs about $871.52 with Global or $860.81 with Fire (about 1.1 SMS/s per GPU, measured), versus gpt-5-mini $2,198.59 and gpt-5.4-mini $5,464.01 at closed-API list prices. Because the model is small and open, extraction can run on-premise, so SMS need never leave the user's infrastructure; we also publish an 8-bit GGUF export for CPU inference and a free Space where anyone can browse every prediction. We release both adapters, the GGUF export, all data splits, every prediction, the CuratorKIT provenance and the AuditKIT run records, and we outline next steps, starting with testing on real bank traffic.

Tiny Aya SMS → JSON

Indian bank and UPI SMS (English, Hindi, Hinglish) turned into an 11-field JSON record by a LoRA fine-tune of CohereLabs/tiny-aya-global. This page lets you browse every test prediction: the gold label next to the regex parser, few-shot prompting and the fine-tuned model. Field values in red are wrong.

Headline metrics

Exact match = all 11 fields right. Hallucination = a field filled with a value that is not in the SMS. Non-txn F1 = detecting messages that mention money but are not transactions (OTPs, offers, bill reminders…).

Browse predictions

This is a static page: it shows recorded predictions and runs no model. To run the model yourself, use the GGUF with llama.cpp on CPU, or the Gradio app in the GitHub repo's space/ folder.
